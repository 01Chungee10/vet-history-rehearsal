# 독일·호주·미국 직업교육훈련의 형성과 변화

[발표 준비실](https://01chungee10.github.io/vet-history-rehearsal/) · [전체 참고문헌](https://01chungee10.github.io/vet-history-rehearsal/#bibliography) · [읽기 순서](https://01chungee10.github.io/vet-history-rehearsal/#reading) · [PowerPoint](https://01chungee10.github.io/vet-history-rehearsal/presentation-r016.pptx)

산업인력개발사 발표 본문 24장, 주요 참고문헌 한 장과 장별 낭독 대본을 수록한 한국어 워크북입니다. 왼쪽은 슬라이드와 대본, 가운데는 자료 목록, 오른쪽은 선택한 자료의 설명과 읽을 위치입니다.

- 첫 장에서 세 교실의 사진을 40초 오프닝으로 재생할 수 있습니다. [한국어 해설 영상](https://01chungee10.github.io/vet-history-rehearsal/media/opening-narrated.mp4)
- 국가별 장표의 오른쪽 위 역사 탐색기에서 시기를 선택해 관련 장표로 이동합니다. 휴대전화에서도 같은 탐색기를 사용할 수 있습니다.
- 목록과 좌우 방향키로 장표를 옮깁니다. 이미지를 누르면 확대되고 Esc로 닫힙니다.
- 장표와 자료를 함께 공유할 수 있습니다. [1917년 스미스·휴스법 원문과 장표](https://01chungee10.github.io/vet-history-rehearsal/#slide-18/ref-smith)
- 전체 참고문헌에서 국가·시대·종류·범위를 선택하거나 제목·저자·기관·보유 파일명으로 검색합니다. 각 서지 항목의 장표 번호를 누르면 해당 자료가 선택된 장표로 이동합니다.
- 보유 원문 34편은 서지 목록에 포함합니다. 실제 PDF를 보유한 사용자는 '보유 PDF 연결'에서 원문 폴더나 개별 파일을 선택하면 원문을 이 기기에서 열 수 있습니다. 브라우저는 파일을 외부 서버로 전송하지 않습니다.
- 장표의 지도·사진·문헌 발췌를 펼치면 이미지 파일과 소장처 기록을 확인할 수 있습니다. 10장과 21장의 애니메이션 도식은 재생 버튼을 누를 때 시작됩니다. 21장에서 제조사 공식 Atlas 영상도 열 수 있습니다.

## 파일

`slides.json`은 장표 본문·대본·자료 키, `sources.json`은 공개 서지·접근 정보·읽을 대목, `holdings.js`는 중복 출처와 연결한 프로젝트 보유 원문 색인입니다. `media/credits.json`에서 지도·사진·도식의 출처를 확인할 수 있습니다. `slides/`에 본문과 참고문헌 장표의 화면을 원본 순서로 저장합니다.

저장소 루트에서 `python3 -m http.server 8000`을 실행한 후 `http://localhost:8000`을 엽니다. GitHub Pages는 main 브랜치 루트를 게시합니다.
