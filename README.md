# 해외 직업교육훈련사 발표 준비실

[발표 준비실 열기](https://01chungee10.github.io/vet-history-rehearsal/)

독일·호주·미국의 직업교육훈련사를 다루는 한국어 발표 워크북입니다. 왼쪽에는 PowerPoint 상영 화면과 낭독 대본, 가운데에는 해당 장의 참고자료, 오른쪽에는 선택한 자료의 해설과 원문에서 확인할 대목이 나옵니다. 문헌이나 사진의 출처를 열어 둔 채 대본을 가리고 발표를 연습할 수 있습니다.

## 탐색

- 상단 목록이나 좌우 방향키로 발표 순서를 이동합니다.
- 슬라이드 이미지를 누르면 확대됩니다. Esc 키를 누르면 닫힙니다.
- 특정 장을 공유할 때는 PowerPoint 원래 장 번호를 사용합니다. [1969년 서독 직업교육훈련법](https://01chungee10.github.io/vet-history-rehearsal/#slide-6)
- 상영 순서는 숨김 장표를 제외한 29장입니다. 내려받는 파일에는 원본의 숨김 장표와 발표자 노트가 포함되어 있습니다.

## 자료 편집

`slides.json`에 장 번호, 대본, 참고자료 키, 연습 질문을 저장합니다. `sources.json`에는 출처별 서지정보와 읽기 해설을 저장합니다. `slides/`의 이미지 파일명은 원본 장 번호입니다. 원문과 사진의 소장처는 각 장의 자료 링크와 PowerPoint의 출처 표기에서 확인할 수 있습니다.

로컬에서 실행하려면 저장소 루트에서 `python3 -m http.server 8000`을 실행한 뒤 브라우저에서 `http://localhost:8000`을 엽니다. GitHub Pages는 main 브랜치의 루트를 게시합니다.
